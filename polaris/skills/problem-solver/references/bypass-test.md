# Bypass cases

## B1 — the fourth attempt with the same frame

A new fix is tried before the attempts are listed. The note shows it: no attempts list, or an
attempts list whose shared assumption is not named.

## B2 — judging before ten

The first plausible hypothesis is evaluated and the rest are never written. The hypothesis table
has fewer than ten rows, or rows with evidence filled before the list was complete.

## B3 — prior art from memory

"Others solve it like this" with no link. Every prior-art line carries a primary source link, or
says the lens found nothing.

## B4 — a test that cannot separate

The chosen experiment would come out the same under every top hypothesis. The note states, for
each top hypothesis, what result it predicts.
